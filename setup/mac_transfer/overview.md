# Mac Transfer

Migration from the Linux machine to `maodou-mac`.

Current status: the Mac is the active workstation. Remaining work lives in
`tasks_outstanding.md`. Completed migration notes are archived in `archive/`.

## Current Direction

- macOS provides the desktop, hardware, trackpad, and app layer.
- Homebrew provides package management.
- Dotfiles provide repeatable shell, editor, terminal, keyboard, and window behavior.
- AeroSpace handles workspaces and tiling.
- Raycast handles app launching and window search.
- Ghostty is the terminal.
